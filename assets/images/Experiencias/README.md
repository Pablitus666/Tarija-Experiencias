## Formato recomendado

- **Formato:** WebP (.webp)
- **Dimensiones:** 1200 × 675 px (16:9) o superior
- **Peso:** Máximo 300 KB por imagen para carga rápida

## Cómo usar

Cuando tengas las imágenes, actualiza los campos `gallery` en:

- `data/experiencias.js` — cambia las rutas a `/assets/images/carousel/experiencias/<id>-1.webp`, etc.
- `data/destinos.js` — cambia las rutas a `/assets/images/carousel/destinos/<id>-1.webp`, etc.

Mientras tanto, el carrusel seguirá mostrando las imágenes de ejemplo actuales.
